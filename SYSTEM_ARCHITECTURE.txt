╔═══════════════════════════════════════════════════════════════════════════╗
║  1. STANDARD LOGIN/REGISTER                                                ║
╚═══════════════════════════════════════════════════════════════════════════╝

User → Click "Anmelden" → Modal Opens → Choose Tab
│
├─── LOGIN Tab:
│    1. Enter email + password
│    2. Submit → POST /api/auth/login
│    3. Backend validates credentials
│    4. Returns JWT token + user info
│    5. Frontend saves token to localStorage
│    6. Page reloads → User logged in ✅
│
└─── REGISTER Tab:
     1. Enter name + email + password + confirm
     2. Submit → POST /api/auth/register
     3. Backend creates user (hashed password)
     4. Returns JWT token + user info
     5. Frontend saves token to localStorage
     6. Page reloads → User logged in ✅


╔═══════════════════════════════════════════════════════════════════════════╗
║  2. GOOGLE OAUTH                                                           ║
╚═══════════════════════════════════════════════════════════════════════════╝

User → Click Google Icon → Redirects to Google
│
1. GET /api/auth/google
2. Backend redirects to Google OAuth consent screen
3. User logs in with Google
4. Google redirects back: GET /api/auth/google/callback?code=...
5. Backend exchanges code for user info
6. Backend creates/finds user (oauth_provider='google')
7. Backend generates JWT token
8. Redirects to: FRONTEND_URL/?auth_token=xxx&user_name=xxx
9. Frontend extracts token from URL
10. Saves to localStorage
11. User logged in ✅


╔═══════════════════════════════════════════════════════════════════════════╗
║  3. MAGIC LINK (Passwordless)                                              ║
╚═══════════════════════════════════════════════════════════════════════════╝

User → Click "Magic Link" Tab → Enter Email
│
1. POST /api/auth/magic-link {"email": "user@example.com"}
2. Backend generates secure token
3. Backend sends email with link (DEV: console.log)
   Link: http://localhost:5500/magic-login?token=xxx
4. User clicks link
5. GET /api/auth/magic-link/verify?token=xxx
6. Backend verifies token (15min expiry)
7. Backend creates/finds user (oauth_provider='magic_link')
8. Backend generates JWT token
9. Redirects to: FRONTEND_URL/?auth_token=xxx
10. Frontend saves token → User logged in ✅


╔═══════════════════════════════════════════════════════════════════════════╗
║  4. FORGOT PASSWORD                                                        ║
╚═══════════════════════════════════════════════════════════════════════════╝

User → Click "Passwort vergessen?" → Enter Email
│
1. POST /api/auth/forgot-password {"email": "user@example.com"}
2. Backend generates reset token
3. Backend sends email with link (DEV: console.log)
   Link: http://localhost:5500/reset-password?token=xxx
4. User clicks link
5. Opens reset page → Enter new password
6. POST /api/auth/reset-password {"token": "xxx", "new_password": "..."}
7. Backend verifies token (30min expiry)
8. Backend updates user password (bcrypt hash)
9. Success message → Redirect to login
10. User can login with new password ✅
